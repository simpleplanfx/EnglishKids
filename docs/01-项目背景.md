# 01 · 项目背景

> 这一篇讲「为什么要做这个东西」以及「做的时候放弃了什么」。
> 想直接上手编译，请跳到 [04-构建与打包.md](04-构建与打包.md)。

---

## 一、起因

家里有个 8 岁小朋友，在上海读三年级。英语学习进入到一个新阶段：不再是看图识字的启蒙期，开始要求**认读、拼写、开口说**。

这个阶段的典型痛点是：

1. **单词记不住**。课堂上学完，回家没有使用场景，第二天就忘大半。
2. **开口机会少**。学校大班教学，一节课轮不到几次朗读，发音问题无人纠正。
3. **默写不过关**。家长报听写要人在旁边，家长不在就练不了。

所以需要一个能让孩子**自己独立完成「听 → 说 → 写」全流程**的工具。

---

## 二、为什么不直接用现成 App

试过几款主流背单词应用后，发现它们和真实需求之间有错位：

| 问题 | 具体表现 |
| --- | --- |
| **词库对不上教材** | 多数 App 按字母序或考纲（中考/高考/KET）组织，和孩子学校这周在学的单元对不上 |
| **强制联网** | 地铁上、飞机上、回老家的路上就废了 |
| **广告与内购** | 孩子自己拿着手机用，误触风险高；核心功能往往锁在付费墙后 |
| **功能臃肿** | 社交、排行、打卡圈……干扰远大于帮助 |
| **隐私顾虑** | 孩子的学习数据、录音被上传到厂商服务器 |

与其在这些 App 里将就，不如针对自家需求做一个**刚好够用的**。

## 三、设计原则

整个项目围绕五条原则展开，所有技术选型都服务于它们：

### 1. 词库必须跟着教材走

词表来源是一线整理稿（见 `source-data/三年级上册英语词汇分类整理.docx`），
按**主题单元**组织（如「人物、家庭成员与职业」「学校与学习用品」），
而不是按字母序。这样孩子可以跟着学校进度，学哪个单元练哪个单元。

### 2. 完全离线可用

网页、词库、CSS/JS 全部打包进 APK（`app/src/main/assets/`），
不依赖任何服务器。**飞行模式下三大功能全部可用**（跟读评分除外，见下文）。

### 3. 零广告、零追踪

代码里没有任何统计、广告、推送 SDK。学习记录只存在手机本地 `localStorage`，
一个字节都不会上传到网络。

### 4. 发音用系统原生能力

不内置音频文件（体积大、覆盖不全），而是调用系统 `TextToSpeech` 引擎。
好处是支持英音/美音切换、语速可调，且能读任意文本（包括后续新增的词）。

### 5. 界面为孩子设计

大按钮、高对比度、即时反馈（星星、进度环、连续打卡）。
所有交互一步可达，不做嵌套层级。

## 四、明确不做的部分

知道不做什么，比知道做什么更重要：

| 不做 | 原因 |
| --- | --- |
| 用户账号与云同步 | 引入服务器成本与隐私风险，单机够用 |
| 社交/排行榜 | 对孩子是干扰，不是激励 |
| 内置音频文件 | 体积膨胀且无法覆盖全部词汇，系统 TTS 更灵活 |
| 平板横屏适配 | 使用场景是手机竖屏，暂不投入 |
| 多语言界面 | 面向中文家庭，界面固定中文 |
| iOS 版本 | 打包与分发成本高，先满足安卓 |

## 五、数据来源与适用对象

- **词表来源**：`source-data/三年级上册英语词汇分类整理.docx`（原始整理稿）
- **教材版本**：上海沪教版 / 牛津上海版（五四制，2024 新教材）
- **覆盖年级**：小学 1–6 年级，13 本词书，1337 个单词
- **当前主词书**：`hj3a` 三年级上册，26 个主题单元，151 词

> 若孩子使用其他教材版本，可直接替换 `app/src/main/assets/data/words.json`，
> 格式与操作步骤见 [05-维护与升级指南.md](05-维护与升级指南.md)。

## 六、技术选型背后的取舍

最终选择 **原生 WebView 外壳 + 网页应用** 的混合方案，而非纯原生或纯跨平台：

| 方案 | 评估 | 结论 |
| --- | --- | --- |
| 纯原生 (Java/Kotlin) | 每改一处 UI 都要重新编译安装，迭代慢 | ❌ |
| Flutter / React Native | 需引入整套运行时，APK 体积暴涨，还要学新框架 | ❌ |
| **原生壳 + WebView** | UI 改网页即时生效；发音/识别走原生桥接；APK 仅 282KB | ✅ |

WebView 方案唯一的顾虑是性能，但本项目是静态页面 + 本地数据，
交互负载很低，实测流畅。而收益是巨大的：

- 改 UI 不用重新编译 APK（直接替换 assets 即可）
- 同一套网页代码未来可复用到 PWA、小程序
- 词库是纯 JSON，家长可自行编辑
