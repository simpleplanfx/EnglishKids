# 04 · 构建与打包

> 从一台干净的 Windows 电脑开始，到拿到可安装的 APK。

---

## 一、两种构建方式

| 方式 | 前置条件 | 适合场景 |
| --- | --- | --- |
| **一键脚本**（推荐） | 无需安装任何东西 | 只想拿到 APK，不想装 Android Studio |
| Android Studio | 已安装 Android Studio | 需要改原生代码、调试、看布局预览 |

---

## 二、方式 A：一键脚本编译

### 操作步骤

1. 双击 `scripts/run_build.bat`
2. 保持网络畅通，**不要关闭窗口**
3. 等待出现 `✅ 完成！APK 已生成：...`

首次运行会自动下载约 **1GB**（JDK 190MB + Android SDK 150MB + 平台/构建工具 ~500MB + Gradle 依赖），
通常需要几分钟到十几分钟。

### 脚本做了什么

```
步骤 1/5   下载并解压 JDK 17              （3 源重试）
步骤 2/5   下载 Android command-line tools（Invoke-WebRequest → curl 双策略）
步骤 3/5   接受许可，安装 platform-34 + build-tools;34.0.0
步骤 4/5   gradlew assembleDebug 编译
步骤 5/5   把 APK 复制到仓库根
```

**脚本是幂等的**：任何一步中断后重新运行，已完成部分自动跳过，不会重复下载。

### 目录布局

脚本会把工具链放在**仓库外**的上一级目录，避免污染仓库（这点很重要）：

```
D:\software\EnglishKidsAPK\              <- 工具链目录 $ToolRoot（仓库外，不入 git）
    jdk17\                               <- JDK 17
    android-sdk\                         <- Android SDK
    EnglishKidsApp\                      <- 仓库根 $RepoRoot（= Android 工程根）
        scripts\build_apk.ps1
        app-debug.apk                    <- 产物
```

想换工具链位置，设置环境变量即可：

```powershell
$env:EKIDS_TOOL_ROOT = 'D:\somewhere\else'
.\scripts\build_apk.ps1
```

## 三、方式 B：Android Studio 编译

1. Android Studio → `File → Open` → 选择本仓库根目录
2. 等待 Gradle Sync 完成
3. 菜单 `Build → Build Bundle(s)/APK(s) → Build APK(s)`
4. 产物在 `app/build/outputs/apk/debug/app-debug.apk`

> 若 Studio 提示找不到 SDK，在 `local.properties` 中指定：
> `sdk.dir=D:\\software\\EnglishKidsAPK\\android-sdk`
> （注意 Windows 路径反斜杠要写成 `\\`。该文件已被 `.gitignore` 排除。）

---

## 四、命令行直接编译

环境已就绪时，最快的方式：

```bash
# 在仓库根目录执行
./gradlew assembleDebug              # Debug 包
./gradlew assembleRelease            # Release 包（需配置签名）
./gradlew clean                      # 清理构建产物
./gradlew installDebug               # 编译并装到连接的手机/模拟器
```

需要先设置（PowerShell）：

```powershell
$env:JAVA_HOME = 'D:\software\EnglishKidsAPK\jdk17'
$env:ANDROID_HOME = 'D:\software\EnglishKidsAPK\android-sdk'
```

---

## 五、安装到手机

1. 把 `app-debug.apk` 传到安卓手机（数据线 / 微信 / 网盘均可）
2. 手机「设置 → 安全/隐私 → 安装未知来源应用」，允许对应来源
3. 点击 APK 完成安装

若有 adb：

```bash
adb install -r app-debug.apk
```

## 六、故障排查

### 下载阶段失败

| 现象 | 处理 |
| --- | --- |
| `基础连接已经关闭` | 脚本已自动重试 6 次。仍失败则换网络（如手机热点）后重跑 |
| 杀毒软件拦截 | 允许或临时关闭后重跑 |
| 公司/校园网限制 | 换网络重跑，已完成步骤会跳过 |

脚本全部重试失败后，会打印手动下载的地址与目标路径，手动放好后重跑即可识别。

### 编译阶段失败

| 现象 | 原因与处理 |
| --- | --- |
| `does not contain a Gradle build` | 工作目录不对，必须在**仓库根**执行。详见 [03-开发过程记录.md](03-开发过程记录.md) 坑 5 |
| `BUILD SUCCESSFUL` 但脚本报失败 | PowerShell `$LASTEXITCODE` 被覆盖，脚本已修复。详见坑 6 |
| `SDK location not found` | 缺少 `local.properties`，或用 `ANDROID_HOME` 环境变量指定 |
| `Unsupported class file major version` | JDK 版本不对，AGP 8.x 需要 **JDK 17** |
| 编译很慢 | 首次需下载 Gradle 与依赖，正常。后续增量编译只需数秒 |

### 设备上使用时的问题

| 现象 | 原因与处理 |
| --- | --- |
| **听不到发音** | 部分安卓手机/平板出厂未装英文语音包。到「设置 → 系统 → 语言与输入法 → 文字转语音(TTS)输出」，引擎选 **Google 文字转语音引擎** → 收听示例 → 按提示下载英文语音包。装好后即为纯离线标准英/美音 |
| 跟读无反应 / 不打分 | 设备缺少语音识别服务。App 会自动降级为自评模式（孩子听回放自行判断） |
| 装 APK 提示「已阻止安装」 | 弹窗中点「设置」→ 允许本次安装未知应用 |
| 界面显示异常 | 系统 WebView 版本过低，到应用商店更新「Android System WebView」 |

### 清理与重来

```bash
./gradlew clean          # 清理构建产物
# 删除工具链（会触发重新下载，约 1GB）
rm -rf ../jdk17 ../android-sdk
```

## 七、产出 Release 版本

Debug 包可直接安装使用。若要正式发布，需要签名：

1. 生成签名密钥

```bash
keytool -genkey -v -keystore englishkids.jks -keyalg RSA -keysize 2048 -validity 10000 -alias englishkids
```

2. 在 `app/build.gradle` 中配置签名

```gradle
android {
    signingConfigs {
        release {
            storeFile file('../englishkids.jks')
            storePassword '***'
            keyAlias 'englishkids'
            keyPassword '***'
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
        }
    }
}
```

3. 编译

```bash
./gradlew assembleRelease
```

> ⚠️ **安全红线**：`.jks` / `.keystore` 已在 `.gitignore` 中排除，
> **绝不要**把签名密钥提交到仓库。密码也应放在环境变量或 `gradle.properties`（同样排除）中，
> 不要硬编码进 `build.gradle`。
