# 英语小超人 (EnglishKids)

> 给家里三年级小朋友做的英语听说默写 App。离线可用，装到安卓手机上就能练。

一个**单词学习工具**，覆盖上海沪教版（牛津上海版）小学 1–6 年级共 **13 本词书、1337 个单词**，围绕「听 → 跟读 → 默写」三个环节设计，帮孩子把单词真正记住，而不是看一眼就过。

---

## 一、它解决什么问题

市面上的背单词 App 普遍有几个毛病：要联网、有广告、词库对不上孩子学校实际用的教材、功能和收费绑在一起。

这个 App 的取舍很明确：

| 诉求 | 做法 |
| --- | --- |
| **词库要对得上教材** | 词表直接来自学校教材整理稿，按「单元」而非字母序组织 |
| **必须离线可用** | 网页、词库、CSS/JS 全部打包进 APK，飞行模式也能练 |
| **不能有广告和内购** | 零第三方 SDK，零统计埋点，代码里没有任何网络上报 |
| **发音要准** | 调用系统原生 TTS（支持英音/美音），而非机器合成音频文件 |
| **要能跟踪进度** | 本地记录掌握度、连续打卡天数、错词本，数据只存手机本地 |

## 二、三大功能模块

### 1. 听 —— 磨耳朵
- 原生 `TextToSpeech` 发音，支持**英音 / 美音**切换，语速可调
- 支持单词与例句朗读，可循环播放
- 离线可用（系统已装英语 TTS 引擎即可）

### 2. 跟读 —— 开口练
- 调用系统 `SpeechRecognizer` 识别孩子读音，与标准发音比对打分
- 录音可回放，孩子能自己听出差别
- 需要麦克风权限（拒绝也不影响其他模块使用）

### 3. 默写 —— 检验掌握
- 看中文写英文 / 听发音写英文两种模式
- 自动判分，错题自动进**错词本**，便于针对性复习

配套：星星激励、每日学习时长统计、连续打卡天数、掌握度进度环。

## 三、技术架构

采用 **原生外壳 + 网页内核** 的混合结构：

```
┌─────────────────────────────────────────┐
│  Android 原生层 (Java)                   │
│  MainActivity.java                      │
│   ├─ WebView 容器（加载 assets 内网页）  │
│   ├─ TextToSpeech  → AndroidTTS 桥      │  离线发音
│   └─ SpeechRecognizer → AndroidASR 桥   │  跟读评分
└──────────────┬──────────────────────────┘
               │ addJavascriptInterface
┌──────────────▼──────────────────────────┐
│  网页层 (HTML + CSS + 原生 JS)           │
│   index.html                            │
│   ├─ js/app.js      界面与学习流程       │
│   ├─ js/speech.js   发音 / 录音 / 评分   │
│   ├─ js/store.js    localStorage 进度    │
│   └─ data/words.json  词库（1337 词）    │
└─────────────────────────────────────────┘
```

**为什么这么选**：UI 迭代改网页即可，不用重新编译 APK；而发音、语音识别这类必须走原生能力的功能，用 JS 桥接暴露给网页。两者各取所长。

| 项目 | 值 |
| --- | --- |
| 最低系统 | Android 7.0 (API 24) |
| 目标系统 | Android 14 (API 34) |
| 构建工具 | AGP 8.2.2 / Gradle 8.2 / JDK 17 |
| 第三方依赖 | **无**（纯系统 WebView） |
| 包名 | `com.example.englishkids` |
| 产物体积 | 约 282 KB |

## 四、快速开始

### 方式 A：一键脚本编译（推荐，无需装 Android Studio）

```bat
双击  scripts\run_build.bat
```

首次运行会自动下载 JDK 17 + Android SDK（约 1GB），然后编译出 `app-debug.apk`。
脚本是**幂等**的：中途失败或再次运行，已完成步骤自动跳过。

> 详细原理与故障排查见 [docs/04-构建与打包.md](docs/04-构建与打包.md)

### 方式 B：Android Studio 编译

用 Android Studio 打开本目录（仓库根），菜单 `Build → Build Bundle(s)/APK(s) → Build APK(s)`。

### 安装到手机

1. 把 `app-debug.apk` 传到安卓手机（数据线 / 微信 / 网盘均可）
2. 手机「设置 → 安全/隐私 → 安装未知来源应用」，允许对应来源
3. 点击 APK 安装
